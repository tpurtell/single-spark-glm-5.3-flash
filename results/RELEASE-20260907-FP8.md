# FP8 default release, 2026-09-07

The host launcher now selects FP8 MLA cache when neither `KV_CACHE_PROFILE`
nor `KV_CACHE_DTYPE` is set. The rest of the release defaults remain 262,144
tokens, eight images per prompt, video disabled, GPU memory utilization 0.87,
six scheduler slots, a 2048-token scheduler prefill batch, EXL3 prefill
capacity 1024, DFlash2 K5, ReplaySSM, and prefix caching enabled.

NVFP4 remains available with `KV_CACHE_PROFILE=nvfp4`; the legacy
`KV_CACHE_DTYPE=nvfp4_ds_mla` shorthand is also preserved. The invalid-cache
dtype path now fails explicitly instead of silently selecting a profile.

EMU was restarted from the unqualified launcher command and left healthy on
port 8001. The immutable container itself is unchanged: registry digest
`1e91406e…`, local image ID `b5ae51f7…`. The environment receipt records the
actual `fp8_ds_mla` argument and all other settings.
